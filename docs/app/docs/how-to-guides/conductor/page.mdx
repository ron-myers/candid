# Using with Conductor

Integrate Candid with Conductor for PR reviews.

## What is Conductor?

[Conductor](https://conductor.build) is an AI-powered development environment that integrates with GitHub PRs.

## Using Candid in Conductor

When reviewing a PR in Conductor:

```
/candid-review
```

Candid reviews the PR's changes against your Technical.md.

## Workflow

1. Open a PR in Conductor
2. Run `/candid-review`
3. Review findings
4. Apply fixes directly
5. Push updated changes

## Benefits

### Contextual Reviews

Conductor provides full repository context, making Candid reviews more accurate.

### Direct Fixes

Apply fixes directly in the PR branch without switching contexts.

### Consistent Standards

Same Technical.md applies to local development and PR reviews.

## Installation

Candid should already be available if you've installed it:

```bash
npx skills add https://github.com/ron-myers/candid
```

The plugin travels with your Claude Code configuration.
