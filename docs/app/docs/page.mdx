# Welcome to Candid

Candid is a [Claude Code](https://code.claude.com/docs/en/overview) plugin that reviews your code changes before you commit or open a PR. 

By defining your project's [Technical.md](/docs/core-features/technical-md), Candid allows you and your team to specify what issues should block a merge.

It analyzes your git diff, identifies issues, and provides concrete fixes - all without leaving Claude Code.
