# Reference

Complete reference documentation for Candid.

## Commands

| Command | Description |
|---------|-------------|
| `/candid-review` | Run a code review |
| `/candid-init` | Generate Technical.md |
| `/candid-validate-standards` | Validate Technical.md |

## CLI Flags

| Flag | Description |
|------|-------------|
| `--harsh` | Use harsh tone |
| `--constructive` | Use constructive tone |
| `--focus <mode>` | Focus on specific aspect |
| `--exclude <pattern>` | Exclude files matching pattern |
| `--merge-target <branch>` | Compare against specific branch |
| `--re-review` | Compare against last review |
| `--auto-commit` | Auto-commit applied fixes |
| `--fix` | Include fix suggestions (validate-standards) |
