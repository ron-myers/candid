# Your First Review

Run your first code review with Candid.

## Make Some Changes

First, make some changes to your code. Candid reviews your uncommitted changes by default.

## Run the Review

```
/candid-review
```

## Choose Your Tone

Candid will ask you to select a tone:

- **Harsh** - Brutal honesty, no sugar-coating
- **Constructive** - Direct but caring feedback

Choose based on your preference. You can change this anytime.

## Review the Results

Candid presents issues organized by severity:

- 🔥 **Critical** - Fix immediately
- ⚠️ **Major** - Should address before merge
- 📜 **Standards** - Technical.md violations
- 📋 **Code Smell** - Maintainability concerns
- 🤔 **Edge Case** - Unhandled scenarios
- 💭 **Architectural** - Design considerations

## Apply Fixes

Each issue includes a concrete fix. Select which issues to add to your todo list for tracking.
