# Install

Get Candid running in under 5 minutes.

## Requirements

- [Claude Code](https://claude.ai/code) installed and running
- A code project to review

## Install Candid

From a terminal, run:

```bash
npx skills add https://github.com/ron-myers/candid
```

This adds the plugin to Claude Code in your environment.

Then restart Claude Code to activate the plugin.

## Verify Installation

After restarting, run:

```
/candid-review
```

You should see Candid analyze your current changes and present review options.
